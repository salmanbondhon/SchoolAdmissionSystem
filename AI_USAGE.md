# AI Usage – School Admission System

## AI Tools Used
- ChatGPT (OpenAI)

## Overview

AI assistance was used as a supporting tool during the development of the School Admission System. The approximate contribution distribution was:

## Areas of AI Assistance
- Understanding technical requirements and architecture.
- Getting guidance on ASP.NET Core, React, and PostgreSQL.
- Reviewing code and discussing implementation improvements.
- Troubleshooting errors and configuration issues.
- Receiving guidance on Docker, testing, and documentation.

## Developer Contributions
- Designed and implemented the application.
- Developed backend APIs and business logic.
- Integrated PostgreSQL using Entity Framework Core.
- Built the React frontend and API integration.
- Implemented reservation, confirmation, cancellation, and expiration workflows.
- Configured Docker and Docker Compose.
- Executed tests, debugged issues, and verified application functionality.
- Managed Git commits and GitHub deployment.

## Transparency Statement

AI was used for technical guidance, suggestions, and troubleshooting. The developer actively participated in implementation, integration, testing, debugging, and deployment. All AI-assisted suggestions were reviewed before being incorporated into the project.
